# Improve accessibility (ARIA, keyboard nav, color contrast)

## Description
Audit and enhance accessibility across all UI components and user flows. Ensure ARIA attributes, keyboard navigation, and color contrast meet or exceed WCAG standards. Test with screen readers and accessibility tools.

## Acceptance Criteria
- [ ] ARIA attributes added to all relevant components
- [ ] Keyboard navigation supported throughout the app
- [ ] Color contrast meets WCAG AA/AAA standards
- [ ] Accessibility tested with screen readers and tools
- [ ] Accessibility improvements documented

## Technical Details
- Use accessibility testing tools (axe, Lighthouse, etc.)
- Reference WCAG and ARIA guidelines
- Document all improvements and known limitations
